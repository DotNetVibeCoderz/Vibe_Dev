# Marketing copy

1. Brief: audience, problem, promise, proof, desired action, tone, channel, length limits.
2. Message hierarchy: one core promise → 3 supporting benefits → proof points.
3. Write variants:
   - Headlines ×3 (benefit, curiosity, specificity angles).
   - Body copy (short + long).
   - CTA ×3 (verb-first, specific: "Start free trial", not "Submit").
4. Channel rules: Ads ≤ 125 chars primary text; email subject ≤ 50 chars + preheader; LinkedIn hook in first 2 lines.
5. Check: concrete over vague, no unverifiable superlatives, inclusive language, localized (not literal) Indonesian.

Deliver `copy/<campaign>.md` with labelled variants.
