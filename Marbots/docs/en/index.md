# Marbots documentation

[English](../en/index.md) · [Bahasa Indonesia](../id/index.md)

Marbots (Marvelous Bots) is a multi-agent collaboration platform on .NET 10. You give goals to **Boss Man**, who
plans the work and hands it to a team of AI coworkers. Each coworker has its own persona, memory, skills, MCP tools
and permission boundaries.
