# Glossary / Glosarium

| English | Bahasa Indonesia | Meaning |
|---|---|---|
| Bot | Bot | A durable AI teammate with persona, memory, tools and permissions |
| Boss Man | Boss Man | The protected manager bot that plans and delegates |
| Thread | Utas | A conversation with one bot |
| Task | Tugas | A durable unit of work; delegation creates child tasks |
| Delegation | Delegasi | Handing sub-tasks to teammates (`delegate_tasks`) |
| Workspace | Workspace | The project folder shared by bots working on a thread |
| Skill | Skill | A SKILL.md instruction package loaded on demand |
| Kernel function | Kernel function | A built-in tool (files, shell, web, …) |
| MCP server | Server MCP | An external tool provider using the Model Context Protocol |
| Permission profile | Profil izin | Maps tool categories to allow / ask / deny |
| Approval | Persetujuan | A human decision on a risky action |
| Long-term memory | Memori jangka panjang | Facts recalled across conversations |
| Context compaction | Pemadatan konteks | Summarising old turns to keep context small |
| Auto-Learn | Auto-Learn | Optional learning of memories and draft skills |
| Template gallery | Galeri templat | Ready-made bot roles |
| Schedule | Jadwal | A cron or one-off job that sends a prompt to a bot |
| Host | Host | A machine that runs bots (local today; remote hosts on the roadmap) |
| Office | Kantor | The live floor-plan view of the team |
