buatkan clone claude code dengan nama "Auto Code", dibuat dengan .NET dan memanfaatkan semua library yang ada di .NET seperti Microsoft Agent Framework, Microsoft Extensions AI, Microsoft Extensions Vector Data, Semantic Kernel, dengan UI EX yang sama. Hanya support ke berbagai model LLM yang bisa di konfigurasi dari aplikasi atau app.config seperti OpenAI, Anthropic, Gemini, Ollama, DeepSeek, Qwen, dsb (open ai compatible endpoint)

 🔑 Fitur Utama Claude Code

- Agentic loop  
  Claude bekerja dalam tiga fase: *gather context*, *take action*, dan *verify results*. Ia bisa mengulang siklus ini berkali‑kali untuk debugging, refactor, atau implementasi fitur.

- Code understanding  
  Membaca dan memahami kode lintas bahasa, menelusuri eksekusi fungsi, data flow, serta mengenali arsitektur dan framework.

- Code generation & modification  
  Mengubah requirement natural language menjadi kode, memperbaiki bug, melakukan refactor, menulis unit test, dan memperbarui dokumentasi.

- Development automation  
  Menjalankan build tools, test, script, CI/CD, package management, hingga operasi database (migrasi, query, schema).

- Integration features  
  Mendukung MCP (Model Context Protocol), utilities Unix, integrasi IDE (VS Code, Cursor), serta koneksi ke layanan eksternal seperti Google Drive, Figma, Slack.

- Extensibility  
  Bisa diperluas dengan CLAUDE.md (persistent context), skills (workflow reusable), subagents (isolated execution), agent teams (koordinasi multi‑agent), hooks (trigger lifecycle), dan plugins.

- Advanced features  
  Termasuk extended reasoning, parallel sessions, structured output (JSON, streaming), multi‑agent coordination, dan cost tracking API usage.
