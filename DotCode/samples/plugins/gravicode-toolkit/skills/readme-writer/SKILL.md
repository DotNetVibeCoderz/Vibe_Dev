# README writer

1. Inspect the project: manifest files (package.json, *.csproj, pyproject.toml, go.mod…), entry points, scripts and existing docs.
2. Write `README.md` with: title + one-line pitch, badges placeholder, **Features**, **Quick start** (install + run commands that actually exist in the project), **Usage** examples, **Configuration**, **Development** (build/test commands), **License**.
3. Only document commands you verified in the project files. Keep it concise and skimmable.
